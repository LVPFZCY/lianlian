# 恋恋开心学习养成岛 🏝️

一个卡通风格的幼小衔接亲子学习系统网页应用。主色调暖黄色，简洁干净。

## 功能模块
- 🏠 首页：学习概览与今日进度
- 🔤 识字：汉字闪卡（点击翻看拼音）
- 🔤 英语：趣味单词卡
- ➕ 数学：加法闯关小游戏
- 📜 古诗：经典唐诗欣赏
- 📚 阅读：绘本故事
- 🧩 思维：动脑小游戏
- 🌈 其他：画画、儿歌、设置等

## 本地预览
直接用浏览器打开 `index.html` 即可，无需任何构建步骤。

## 部署（GitHub Pages）
本项目已配置 GitHub Actions 自动部署到 GitHub Pages。

1. 将代码推送到 GitHub 仓库（main 分支）
2. 在仓库 **Settings → Pages → Build and deployment → Source** 选择 **GitHub Actions**
3. 推送后 Actions 会自动构建并发布，访问 `https://<用户名>.github.io/<仓库名>/`
